📚 BookNova

BookNova is a Full-Stack Online Bookstore built using React.js and Django REST Framework. It allows users to browse books, read previews online, purchase books securely using Razorpay, and manage their orders through an intuitive and responsive interface.

🚀 Live Demo

🌐 Website:
https://booknova-tzld.vercel.app/

💻 GitHub Repository:
https://github.com/PoojaR2804/BOOKNOVA

✨ Features
🔐 User Registration & Login (JWT Authentication)
📚 Browse books by category
🔍 Search books
📖 View detailed book information
📖 Read books online
⬇️ Download available book PDFs
🛒 Add books to Cart
⚡ Buy Now option
💳 Secure payment using Razorpay
📦 Order history
📱 Fully responsive design

⚙️ Installation
Clone the repository:
git clone https://github.com/PoojaR2804/BOOKNOVA.git
Backend:

cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
Frontend:

cd frontend

npm install

npm run dev
